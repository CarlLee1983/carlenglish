# 台灣小學生初級讀本：素材與驗證

日期：2026-10-25。本批新增六篇 `入門` 場景，沿用現有 JSON、閱讀頁、初級目錄、逐句朗讀與複習卡契約，沒有新增資料類型、依賴或互動功能。

## 交付範圍

- `content/scenes/`：`breakfast-shop-order`、`rainy-school-day`、`pretend-picnic`、`feelings-break`、`classroom-cleanup`、`night-market-fruit`。每篇 6 句、4 組短句、6 個單字；共 36 句、24 組短句、36 個單字。
- `public/images/scenes/<id>.webp`：六張原創插畫，皆 1536 × 1024，內建 image_gen 各生成一次；未使用 CLI/API fallback、第三方圖片或角色參考圖。完整構圖以 sharp quality 86 轉 WebP，無裁切。逐張檢查人物、活動、物品與安全情境，並依插畫校正文案的代名詞、蠟筆與打掃分工。
- `public/audio/{sentences,phrases,words}/`：本批 96 段 MP3，使用現有固定美式女聲；僅處理本批新場景。輸入、合成器實際消耗文字、聲線與檔案雜湊保留在 `docs/audio-generation/elementary-beginners-20261025/`。
- [學習說明](elementary-beginners-study-guide.md)：共讀順序、六組理解與口說練習、分開的參考答案，以及 Bluey 官方首頁選讀入口與原創觀察任務。

所有插畫完整指令、生成檔名與使用路徑見 [圖像紀錄](elementary-beginners-image-manifest.json)。圖片是教學示意，不是台灣真實店家、學校或人物的紀錄。

- 瀏覽器：1,763 passed、12 skipped，涵蓋桌面 Chromium、深色模式、390 px 與 320 px Chromium、手機 WebKit。12 項為既有依平台設定的條件略過：iOS 主畫面提示只在適用平台檢查，共用音訊解碼只在代表性的 Chromium 與 WebKit 執行，沒有新增略過。

- 本批音訊：96 段的文字與檔案 SHA-256、聲線 ID、完整文字消耗與 FFmpeg 解碼全部通過；共 1,463,688 bytes、182.525 秒。數值與檢查結果見音訊目錄的 `validation.json`。

## 驗收界線

英文、繁體中文、字詞標註與圖文對應已人工校讀。格式、雜湊、解碼與瀏覽器播放檢查，不能代替家長與孩子的實聽和試讀；本批尚未取得使用者對發音、0.8× 跟讀節奏及難度的驗收。舊批次的聲線接受紀錄不等於新批次已驗收。

Bluey 只作外部作品辨識與選讀參考，不複製或改寫節目素材。來源及採用方式見學習說明的版權段落。未驗證台灣帳號的外部平台片庫或地區播放權限；六篇本站讀本可以獨立使用。內容交付時尚未提交、推送或部署；後續使用者已授權收尾上線，流程與回復目標見 [發布紀錄](implementation.md#2026-10-25-台灣小學生初級單元發布)，實際發布結果以對應 Actions run 與部署回報為準。
