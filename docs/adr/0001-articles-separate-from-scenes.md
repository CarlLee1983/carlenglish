# 文章是獨立於場景的內容類型

新聞與貼文教材以獨立的「文章」內容類型呈現，有自己的資料目錄、驗證與路由，不放寬場景契約。場景的 5–8 句、必填插圖、短句與單字數量、全文雜湊音檔，都是它作為生活讀本的品質保證；新聞需要的是段落、來源與日期、讀後提問，貼文需要發文者與回覆關係。把兩者塞進同一份契約，只能把場景的每條驗證都改成條件式，削弱已上線的檢查。代價是兩套內容入口各自維護，共用的只有欄位驗證的小工具。

2026-10-14 使用者決定略過「先在對話取得閱讀證據」，直接實作；本決定與第一版的不附音檔、讀後提問附可展開的參考答案且不保存、原創貼文自製卡片而真實貼文只放連結、以軌道加級別標示難度，一起記錄在 [新聞與社群貼文閱讀企劃](../news-social-reading-plan.md)。

**Falsified if:** 文章與場景的必填欄位開始大量重疊，例如文章也一律需要插圖、短句與單字，而 `src/lib/articles.ts` 與 `src/lib/scenes.ts` 的驗證邏輯多半互相複製；這時合併成同一種內容類型會比較簡單。
