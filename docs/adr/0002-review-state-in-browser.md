# 複習紀錄只存在學習者的瀏覽器

字卡與複習排程是網站第一份使用者狀態，存在瀏覽器本機，並提供匯出／匯入備份檔讓學習者自行搬到別的裝置；不加後端、不做帳號。網站目前是部署在 Cloudflare assets 上的純靜態站，加上 D1 與登入，會讓部署、隱私、資安與維運一次變重，而眼前只有一位學習者。代價是手機與電腦各有一份進度，換裝置要手動搬備份；瀏覽器清除網站資料時，沒有備份的進度會遺失。最大的風險在 iPhone：Safari 會在連續使用 Safari 7 天、期間都沒開過本站時，清除本站所有指令碼可寫入的儲存；加到主畫面的 web app 不受這條限制（[WebKit 儲存政策](https://webkit.org/blog/14403/updates-to-storage-policy/)）。所以複習頁會引導學習者加到主畫面，並申請持久儲存。

**Falsified if:** 學習者實際上經常在兩台以上裝置之間複習、手動搬備份成為負擔，或瀏覽器清除資料造成進度遺失；這時改用後端儲存與帳號同步會比較划算，`src/lib/review-storage.ts` 是需要替換的儲存邊界。
