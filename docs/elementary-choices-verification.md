## 驗收界線與回復

本批為原創教學創作，不使用第三方節目、角色或歌曲素材。使用者與孩子尚未實聽、試讀本批。此環境可核對文字、媒體與原生播放事件，無法主觀聆聽發音，也不能代替實機觸控或孩子難度驗收；個人閱讀證據維持原樣。

可依[共讀說明](elementary-choices-study-guide.md)每次挑一篇，在自己的手機以 0.8× 播放句子、語塊與詞彙，確認沒有漏字、發音可懂且節奏適合，再用中文回答理解題。預期能從英文找到答案；可以重聽及使用翻譯，不以篇數或聽完當成已掌握的證據。角色扮演可用插畫與紙畫道具完成。

本次交付為本地教材更新，未提交、推送、建立 PR 或部署。若需回復本批，移除三個新 ID 的 JSON、WebP、48 段 MP3 及本批配套文件，只還原共用 README、內容指南與音源說明中的本批條目及總量。前三批九篇及共用素材保留，沒有學習紀錄或資料遷移要回復。沒有獨立 handoff 需要改寫或刪除，本文件記錄本批狀態及人工驗收方式。
