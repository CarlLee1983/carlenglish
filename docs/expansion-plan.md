# CarlEnglish 場景與學習卡擴充企劃

日期：2026-10-14。狀態：企劃草案，供後續分批實作。

同日內容更新：和新同學打招呼已先行完成；依新的中高階擴充需求，本次分支再加入 respectful-disagreement、checking-online-information、giving-short-presentation 三篇，組成換書活動單元。這是選題與批次的調整，未代表原企劃各階段、學習卡或自動發布已完成。原企劃數量與排程保留為歷史規劃，現況以 README 及 [本批驗證紀錄](book-swap-verification.md) 為準。

先擴充小朋友與中學生熟悉的生活情境，再讓每個場景的單字與短句成為可獨立操作的複習卡。規劃新增 40 個場景，加上現有 3 篇，共 43 篇；第一批先做 8 篇，確認內容難度、圖文與朗讀品質後，再接續擴充。

本次交付為情境目錄、製作準則、卡片流程與分階段驗收規劃。場景表中的英文是選題用的候選用語，尚未製成正式讀本、圖片或音檔。

## 產品方向與現有基礎

每個情境聚焦一個能在生活中完成的小任務，例如向同學借鉛筆、選午餐、安排小組分工。學習路徑為「看圖理解情境 → 閱讀並聽短文 → 練習單字 → 練習短句 → 回到情境使用」。

目前已有咖啡店買早餐、超市購物、街上問路，合計 24 個單字、15 個短句與 3 篇短文，皆有本地音檔。閱讀頁已呈現單字與短句清單；後續的學習卡會增加逐張出題、顯示答案與切換的複習流程。

沿用 [現行規格](spec.md) 與 [內容維護說明](content-guide.md)：一份場景 JSON、一張圖片、5–8 句雙語短文、4–6 個短句、6–8 個單字，以及全文、短句、單字的固定聲線 MP3。新增同類型讀本沿用共用 Reader 與既有路由；分眾導覽與卡片模式另外安排程式實作。

## 受眾與內容難度

年齡是選題參考；英文程度另行判斷。國高中學生也能使用入門內容，小朋友也可在家長協助下閱讀較進階內容。以下是編輯用的分組，並非正式能力分級或學校課綱對照。

| 受眾 | 選題重點 | 文字與互動方向 |
| --- | --- | --- |
| 小朋友，約 6–9 歲 | 家庭、教室、玩耍、飲食與物品 | 以可看見的物品、動作與需求為主；一個情境只完成一件事，重複自然句型，支援親子共讀 |
| 小朋友，約 9–12 歲 | 借物、作息、照顧、合作與校外活動 | 加入簡單原因、順序與禮貌請求；保留具體的圖片線索 |
| 國中生，約 12–15 歲 | 同儕、社團、校園、交通與休閒 | 用自然的同學對話，練習詢問、邀請、分工與澄清；圖片和語氣符合青少年生活 |
| 高中生，約 15–18 歲 | 表達意見、簡報、交流、資訊判讀與學習規劃 | 在既有短篇長度內增加理由、選擇與回應，避免一次加入太多新詞 |
| 親子與一般生活 | 家庭合作、公共場所、旅行與尋求協助 | 不綁定學校年級，讓不同年齡共用同一個生活任務 |

小朋友情境中需要協助時，角色以家人、老師或場所工作人員為主。青少年內容保留自主選擇、友誼與合作；不以幼兒語氣包裝中學生題材。

## 場景製作與品質準則

每篇先寫出「誰，在什麼地方，為了什麼需求，說了什麼，最後完成什麼」。短文圍繞一個主線，不把多個生活任務塞進同一篇。所有短句與單字必須實際出現在短文並建立明確引用；先確定用語再製圖與音檔。

| 製作項目 | 驗收重點 |
| --- | --- |
| 學習任務 | 能用一句中文說明讀完後要練習的生活行為 |
| 英文短文 | 5–8 句，句子自然、人物與事件連貫；入門篇減少新資訊，較進階篇增加理由與回應 |
| 常用短句 | 4–6 個可直接使用的表達，有正確繁體中文意思，能在本情境使用 |
| 重點單字 | 6–8 個，意思依本篇情境決定；例句簡短，避免用更多陌生字解釋一個詞 |
| 繁體中文 | 保留原意與語氣，逐句對應；兒童與中學生都能理解 |
| 場景圖片 | 人物年齡、場所、物品與主要動作對上短文；重要物品可辨識，替代文字描述主要活動 |
| 聲音 | 沿用固定 Kokoro `af_heart` 美式女聲，逐段實聽發音與自然度，音檔與精確英文及雜湊相符 |
| 延續性 | 新場景複用少量已學用語，再加入新用語；相同英文可重用音檔，不合併不同情境的詞義 |

### 第一批的兩個製作範例

**課堂借物與求助，面向小朋友。** 圖片呈現兩位同學在教室借鉛筆，老師在附近。故事依序交代忘記帶鉛筆、提出請求、同學回應、道謝與歸還，完成一個禮貌借物任務。候選單字為 pencil、eraser、ruler、desk、classmate、teacher；候選短句為 Can I borrow a pencil?、Here you are.、Thank you.、You're welcome.。正式短文須自然帶入全部學習項目，不能為了湊數列舉物品。

**小組作業分工，面向國中生。** 圖片呈現同學圍著桌面討論海報。故事交代作業主題、詢問分工、認領工作與約定完成時間。候選單字為 project、group、poster、picture、meeting、Friday；候選短句為 What should we do first?、I can make the poster.、Can you find some pictures?、Let's meet on Friday.。學生能練習提出建議、表達能做什麼，以及確認下一步。

## 單字卡與短句卡

### 第一版單字卡

從場景閱讀頁進入「練單字」，使用本場景的 6–8 個單字。正面顯示英文與手動播放按鈕；點選「看答案」後顯示中文意思與既有英文例句。提供上一張、下一張、目前張數與返回讀本。第一版沿用單字陣列順序，不做跨場景抽題。

例如 `classroom-help` 的 pencil 卡：正面為 pencil；背面為「鉛筆」與該場景的正式例句，附上返回原情境的入口。播放沿用該單字既有音檔。

### 第一版短句卡

從閱讀頁進入「練短句」，使用本場景的 4–6 個短句。正面顯示既有中文意思，讓學習者先試著說英文；「看答案」顯示英文與手動朗讀按鈕。提供上一張、下一張、目前張數與返回讀本。

例如正面「我可以借一支鉛筆嗎？」；背面為 Can I borrow a pencil?。短句卡保留場景標題與返回原文入口，讓學習者知道這句話對誰、在什麼場合使用。自訂對話回應、填空與句型替換另放在後續階段，所需內容與音檔另外驗收。

### 卡片資料與互動邊界

- 場景 JSON 是文字與音檔的唯一來源。單字卡取自 `words`，短句卡取自 `phrases`，不另維護手寫卡片目錄。
- 卡片以「場景 ID、種類、項目 ID」共同識別。相同拼字在不同情境可能有不同意思，第一版保留各自的翻譯與例句。
- 換卡、換場景與重新開始時收合答案。到首張或末張有明確邊界；不默默跳到其他場景。完成最後一張後可重新練習或回到讀本，不把翻卡次數當成已學會。
- 手動觸發播放，同時最多一段；換卡、離開頁面或頁面隱藏時停止。沿用音訊控制的錯誤提示與舊事件隔離，避免前一張卡的播放狀態覆蓋新卡。
- 操作按鈕至少 44px 高，可用鍵盤完成；答案狀態與張數能被輔助技術辨識。不依賴滑動手勢或翻面動畫才能完成練習。
- 第一版只保留本次頁面內的練習狀態；登入、跨裝置同步、熟悉度紀錄、間隔複習與評分另立規格。

## 分眾導覽與技術安排

2026-10-14 另依使用者要求實作初／中／高級導覽、同級主題篩選與搜尋，見 [UI 導覽說明](ui-navigation.md)。這是英文難度分組；本節後續規劃的年齡受眾欄位與入口仍未實作。

前兩批選題的受眾先由本企劃與內容審閱管理。現有 `category` 表示生活分類，`level` 表示難度；兩者不承擔年齡分組。場景增加後，分眾導覽增加「小朋友、國中生、高中生、親子與生活」入口，也保留全部場景入口。

分眾實作時，在集中內容入口增加一個必填、經驗證的主要受眾欄位，例如 `audience` 的 `children`、`junior-high`、`senior-high`、`general`。一次更新當時全部正式場景；現有咖啡店、超市、問路歸入一般生活。仍從場景檔案自動發現內容，不另建立人工場景清單。初版採主要受眾單選，真有跨組搜尋需求時再設計多標籤。

列表目前依 JSON 檔名排序，企劃中的批次不是網站上的學習順序。第一版卡片以單一場景為範圍；全站課程順序、跨場景牌組與搜尋留待內容量和實際使用需求明確後處理。

新增場景前，調整現有測試中「恰好三個場景」的假設，包括 `tests/browser.spec.ts` 與 `tests/extension.test.mjs`。改為驗證實際內容集合、保留原三場景，以及隔離副本新增一篇後的自動列表與路由。`tests/pronunciation.spec.ts` 目前只讀取指定的三篇，也須讓新增場景取得音訊驗證，並依每篇實際項目數檢查按鈕。保留缺資產、懸空引用、無效音檔等錯誤攔截，不為了擴充移除原驗證。

新音檔製作需先準備可重現的隔離 Python 與模型環境，依 [音訊來源](audio-sources.md) 核對版本。repository 不含本機模型或 `.scratch/` 環境；現有生成工具會處理所有場景，執行前後須檢查資料及資產差異，避免連帶重製既有音檔。網站建置與讀者播放仍只使用完成的本地資產。

### 每個內容批次的驗收

1. 每篇能清楚說明目標受眾與生活任務，人工核對英文自然度、翻譯、圖片及全部音檔；沿用未變動內容已通過的結果。

3. 正式內容驗證與 `pnpm run verify` 通過；更新受影響的擴充測試，保持隔離副本不污染正式資料。

5. 記錄新增場景、內容和媒體驗收、工程檢查與仍待處理事項；更新維護說明。內容通過不等於學生已掌握用語。

### 卡片與分眾功能的驗收

1. 分眾入口的場景集合與受眾欄位一致，全部入口涵蓋完整內容；每個場景網址保持不變。
2. 卡片數量、英文、中文、單字例句與音檔逐項對上原場景；同拼字不同詞義、不同場景的同名 ID 不互相覆蓋。
3. 顯示答案、上一張、下一張、重新開始與返回閱讀能用觸控及鍵盤完成；換卡後答案與播放狀態正確重設。
4. 音訊跨卡片及種類切換不重疊；舊事件與 Promise、播放失敗、頁面隱藏或離開等行為有回歸覆蓋。
5. 手機 Chromium 與 WebKit 的版面與行為檢查通過，再於實際手機確認播放和觸控；`pnpm run verify` 全部通過。
