# 小學生生活英文：搭積木、買麵包、收畫具

這三篇接續[輪流玩、幫忙裝水、準備明天](elementary-routines-study-guide.md)，練習一起完成積木塔、回應店家的提問，以及詢問用品的收納位置。每篇 6 句、4 組語塊、6 個單字，搭配繁體中文、原創插畫與固定聲線。「入門」是編輯分級，不對應學校年級或 CEFR 認證；每篇可以獨立閱讀。

## 語塊與容易混淆的地方

- `builds a tower` 是搭一座高塔，正文敘述小柏的動作用 `Bo builds`；換成自己說可用 `I build a tower.`。小柏先放一塊大積木，小安再加上兩塊小積木，`on top` 指加在上面。合起來是三塊，不是三塊小積木。`Can it stand?` 問這座塔能否立住，`it` 指積木塔；`let go` 是兩個孩子放手。最後 `It stands!` 表示這次塔立住了，`stand` 和 `stands` 是同一個意思的不同字形。這是故事的結果，不是所有積木塔都能立住的保證，也不是搭建操作教學。
- `bakery` 是麵包店這個地方，`baker` 是麵包師傅這個人。`Two rolls, please` 是請給兩個小圓麵包；`rolls` 可以按個數計算，`bread` 是不可數的麵包總稱，這裡不用 `two breads`。`Would you like a bag?` 是提供袋子的提問，`Yes, please` 表示接受。`he asks` 的 `he` 指麵包師傅，`she tells` 的 `she` 指小美。`in a bag` 是在袋子裡，最後正文直接寫麵包是 `warm`（溫熱的），不用靠插畫判斷溫度。正文沒有交代價格、袋子費用、付款過程或花了多久。
- `art tools` 在這裡泛指畫畫用品，`brushes` 和 `crayons` 分別是複數的畫筆與蠟筆。`after class` 是下課後。小宇先把畫筆放進罐子，接著問 `Where do these crayons go?`，是在問這些蠟筆的收納位置，不是問如何製作蠟筆。老師回答 `In this box`，指定這個盒子。之後小宇蓋好盒子，把紙張疊好，最後說 `my desk is tidy`（我的桌面整齊了）。插畫呈現盒子仍開著、正在收蠟筆的時刻，蓋好盒子是後面的動作。

回答正文理解題時，回到六句英文找依據。單字例句是獨立練習句，不把例句中的額外資訊加入故事；插畫也不需要同時呈現所有步驟。

## 理解與口說練習

先回答，再看文末的參考答案。活動可以只用插畫與紙畫道具完成。

| 讀本 | 理解題（回看英文） | 口說或操作 |
| --- | --- | --- |
| 一起搭積木塔 | 小柏和誰搭塔？誰放大積木，放在哪裡？小安加了幾塊什麼樣的積木？誰放手看著塔？最後塔立住了嗎？ | 指著畫好的塔，用本篇問句詢問能不能立住；找出「在上面」與「放手」的語塊。說自己的動作時練習說 I build a tower. |
| 到麵包店買麵包 | 小美和誰去麵包店？她要幾個小圓麵包？誰問她需不需要袋子？她怎麼回答？麵包放在哪裡？她帶回家的麵包是什麼溫度？ | 扮顧客的人請給兩個小圓麵包；扮麵包師傅的人問需不需要袋子，顧客用本篇句子接受。 |
| 整理畫畫用品 | 小宇什麼時候整理用品？畫筆放在哪裡？他問哪一種用品要放哪裡？老師指示放在哪裡？之後他對盒子和紙分別做什麼？ | 指著蠟筆圖卡問放哪裡，同伴用本篇語塊指定盒子；整理好後說「現在我的桌面整齊了」。 |

## 參考答案

1. 小柏和小安搭塔。小柏把一塊大積木放在地毯上，小安在上面加兩塊小積木；兩人一起放手看著塔，最後塔立住了。口說可問 “Can it stand?”；對應語塊是 “on top” 和 “let go”。換成自己敘述可說 “I build a tower.”。
2. 小美和爸爸去麵包店，要兩個小圓麵包。麵包師傅問是否需要袋子，她接受；師傅把麵包放進袋子，小美帶溫熱的麵包回家。口說可依序說 “Two rolls, please.”、“Would you like a bag?” 和 “Yes, please.”；位置語塊是 “in a bag”。
3. 小宇下課後（after class）整理用品，把畫筆放進罐子。他問蠟筆要放哪裡，老師回答在這個盒子裡；之後小宇蓋好盒子、疊好紙張。口說可說 “Where do these crayons go?”、“In this box.” 和 “Now my desk is tidy!”。
