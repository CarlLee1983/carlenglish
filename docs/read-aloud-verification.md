# 生活讀本朗讀改善：驗證與實聽

日期：2026-10-25。範圍與產品決策見 [設計文件](read-aloud-design.md)，音檔取捨見 [ADR 0003](adr/0003-sentence-audio-for-guided-reading.md)。

使用者指出原本跟讀須隨正文捲動，並選擇 A「獨立專注跟讀」。A 已整合正式讀本，全部檢查與獨立審查完成；本文另保留第一版的歷史檢查證據。使用者尚未確認實際手機體驗。

## 交付內容

- 46 篇生活讀本共 321 段逐句音檔，沿用 Kokoro `af_heart` 固定美式女聲。逐句／連續模式共用這批音檔，移除原本的 46 段整篇音檔與相應資料契約。
- 初級預設逐句跟讀與 `0.8×`，中／高級預設連續朗讀與 `1×`；提供四種語速並保存手動選擇的偏好。
- 一般閱讀保留整篇正文與翻譯，只有「開始跟讀」或接續入口。A 專注跟讀以原生全螢幕 dialog 呈現，目前句子、翻譯開關、語速與底部操作同屏；同一顆主按鈕處理播放、暫停、繼續、下一句與完成，重聽和上一句為次要操作。跳句、模式與從頭朗讀收在設定中。
- 退出或按 Escape 時停止播放並回到正文練習句子的可見位置；可到短句／單字區試聽後再手動進入，同頁暫停／繼續保留句內秒數。開啟跟讀與切換句子不自動發聲（主按鈕「下一句」是明確開始下一句的操作）。
- 每篇保存句子位置與聽完狀態。停止、切到背景與離頁後，下次由使用者手動從句首接續。內容或錄音版本改變時，提示從頭開始。
- 儲存讀寫失敗不阻斷播放；提示獨立於播放狀態，不會立刻被播放訊息覆蓋。朗讀儲存使用獨立命名空間，不改動複習與經典的紀錄。
- 內容生成與驗證、場景 JSON-LD、維護說明與測試一併更新，沒有新增套件或遠端語音服務。

## 實際手機驗收

2026-10-25 使用者已授權收尾並上線，候選版本經 PR CI 後合併至 `main`，由既有 Deploy 工作流程發布。實際發布 SHA、結果與平台版本以 [Deploy 紀錄](https://github.com/CarlLee1983/carlenglish/actions/workflows/deploy.yml) 為準。發布完成後可直接用正式網址驗收；本機重現則可在 Mac 的專案目錄啟動預覽：

```sh
pnpm run preview --host 0.0.0.0 --port 4396 --ignore-lock
```

正式網址為 `https://carlenglish.gravito.dev/scenes/cafe-breakfast/#story`。使用本機預覽時，手機與 Mac 連到同一個區域網路後，以 Mac 的區域網路 IP 取代網址中的 `<Mac-IP>`。IP 可在 macOS「系統設定 → 網路」查看。開啟 `http://<Mac-IP>:4396/scenes/cafe-breakfast/#story`，另可抽查 `/scenes/school-greeting/` 與 `/scenes/morning-routine/`。

1. 尚未設定偏好時，確認初級顯示逐句跟讀與 `0.8×`；先點「開始跟讀」進入獨立畫面，再點「播放本句」；確認句末停下、有時間跟讀，而且重聽／下一句始終可見。
2. 切換 `0.7×／0.8×／0.9×／1×`，確認咬字清楚、聲線一致；從「設定」切到連續朗讀，確認相鄰句子的停頓能接受。
3. 播放中按「回到文章」或 Escape，確認回到剛練習的句子；再查一個單字，確認聲音不重疊，手動接續仍回到原句。
4. 聽到第三句後切到背景、返回或關頁重開，確認需點「接續第 3 句跟讀」進入，再點播放才從句首開始。
5. 播放最後一句到結束後完成本輪，確認出現完成畫面；退出重開仍保留聽完狀態，點「再練一次」從第一句開始。

需要回報的是慢速是否清楚、句間停頓是否自然、逐句跟讀節奏是否合適，以及手機有沒有遇到換句或接續失敗。完成後在啟動預覽的終端按 Ctrl-C 關閉服務。

## 限制與回復

朗讀紀錄只在同一瀏覽器，沒有跨裝置同步；清除網站資料會移除紀錄。代表篇實聽不能證明每段錄音的發音都已人工驗收。生成工具實際製作與維護重用路徑已執行，產製期間文字變更與合成失敗的防護以程式審查核對，尚未另外建立自動化的生成器故障注入測試。

若回復功能，須將播放器、場景資料、驗證／生成工具與音檔一併回復，不可只換回舊播放器而保留新句子契約。新增的 `carlenglish.reading.*` 儲存鍵獨立於舊功能；回復版本不會讀取它們。
