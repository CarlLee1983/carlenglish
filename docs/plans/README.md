## 一、 企劃全貌與規格檢驗

- **指標對象**：涵蓋國小高年級、國中生至零基礎成人之「日常獨立生活自理」。
- **詞彙完備基準**：錨定 **NGSL-Spoken 1.2（716 個口語核心字）**。
- **篇數規模**：12 大單元，共 **60 篇生活自理場景**（初級 48 篇、初級至初中級 12 篇）。
- **單篇規格契約**：
  - 雙語正文（Sentences）：5–8 句（具中文翻譯與真實雙向生活互動）
  - 實用短句（Phrases）：4–6 句（日常常用語塊與固定句型）
  - 重點單字（Key Words）：6–8 個（含繁體中文釋義與真實生活英文例句）
  - 語音標準：統一指定 Kokoro `af_heart` 美式女聲本地 MP3

## 三、 實作前置指引（Builder 接手守則）

後續開始實作時，每批（5 篇）需完成：
1. **JSON 建立**：於 `content/scenes/<id>.json` 按照各單元企劃的文字轉換，確保 `segments`、`words`、`phrases`、`audio` 齊備。
2. **語音生成**：使用 Kokoro `af_heart` 美式女聲腳本生成句子、短句與單字之 MP3。
3. **場景圖片**：提供 16:9 圖片置於 `public/images/scenes/<id>.webp`。
4. **驗證合規**：執行 `node scripts/validate-content.mjs` 與 `pnpm run test`。
