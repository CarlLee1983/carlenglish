# 先讀懂，再查單字：兩篇太空新聞的閱讀練習

日期：2026-10-15。這是閱讀練習，不是能力測驗或新聞訂閱。兩篇都按 N2 新聞簡報設計；不表示讀者已達到某種程度。文章使用現行資料契約，不增加圖片、音訊或功能。

## 建議順序

1. [學生的問題即將送上太空](/articles/students-question-astronauts-2026/)：先抓主旨、人事時地，再看第二段如何補充資訊。閱讀 will、scheduled 時，分辨活動預告與活動結果。
2. [耐得住低溫，不等於低溫下仍能供電](/articles/moon-battery-cold-test-2026/)：追蹤問題、測試觀察及限制。利用 without damage、supplying power、heaters 的上下文區分 survive 與 operate，辨認 could、might 的不確定語氣。

兩篇共八題，答案可在文章內找到。第一次先不開翻譯，以中文說出一句主旨。第二次標出支持答案的英文，查真正卡住主旨的少數詞，再打開翻譯、參考答案比較。不能只靠記得譯文判斷讀懂。

讀得吃力可以一次只讀一段；讀得順則沿來源連結試讀同一題材的完整報導，不必強迫立即升到 N3。後續選題依實際閱讀負荷調整，不以篇數自動提高難度。

## 向英文故事閱讀銜接

辨認時間與段落關係，也有助追蹤故事中的先後順序；從上下文猜詞能減少逐字查字典。新聞的「誰說的」可銜接到故事的對話說話者，但角色指涉、動機與隱含意思仍需另用故事練習。《小王子》原作為法文；英文版的譯者與授權要另行核對。本批不收錄該書或翻譯，也不將新聞理解等同小說閱讀能力。

## 來源與逐段查核

兩篇原文均在 2026-10-15 使用助手的雲端瀏覽器開啟並讀到正文末段；不是只讀搜尋摘要。此次選用 NASA 第一手公告，不將其描述成獨立媒體報導。

### 學生問答

- 原文：NASA，Gerelle Q. Dodson，2026-10-14，https://www.nasa.gov/learning-resources/nasa-astronauts-to-answer-questions-from-florida-students/
- 第 1 段：公告首兩段提供兩位太空人、太空站、10/16 中午 EDT。NASA 是消息來源；不宣稱對話已完成。
- 第 2 段：首段及第 3 段確認 prerecorded STEM questions、Sally Ride Elementary School、Orlando、K–12 與社區；第 2 段提供公開直播頻道。教材不捏造學生將問的具體問題或答案。
- 第 3 段：第 3 段說明探索／職涯教育目的；最後兩句是對預告文本能支持什麼的閱讀判斷。
- 日期：publishedAt 10/14；eventDate 10/16 是預定活動日期。EDT UTC−4，臺灣 UTC+8，相差 12 小時，因此為臺灣 10/17 00:00。若讀者之後閱讀，仍按當時公告練習，不能將預告當完成證據。

### 低溫電池

- 原文：NASA，Joe Atkinson，2026-10-14，https://www.nasa.gov/centers-and-facilities/langley/nasa-develops-batteries-to-power-humanitys-return-to-moon/
- 第 1 段：開頭與 Splashy problem, solid solution 節說明低溫問題與固態電解質方向。
- 第 2 段：該節記載小型 prototype cells 在 −80°C 效能略降，以及經 −170°C 暴露不受損；隨後明確說明不能在 −170°C 供電。教材保留這項區別，沒有把存活溫度寫成運作溫度。
- 第 3 段：加熱器段說明回溫至工作溫度與可能減少持續加熱的需求；文章末段仍將計畫定位為技術開發。減重是研究者提出的可能好處，不是實測量化結果。
- 日期：原文未提供測試日，只有 recent testing。eventDate 用 10/14 公告日，背景卡明示此限制，不捏造試驗日期。
