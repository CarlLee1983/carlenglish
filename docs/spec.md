## Problem Statement

學習者希望透過具體的生活情境，培養英文語感並累積能直接開口使用的短句與單字。需要一個簡單、適合手機閱讀的圖文網站，讓圖片、短文與用語彼此對應，不必經過複雜操作就能開始學習。

網站也需要能持續增加場景，而不是每增加一篇內容就重寫頁面。第一版以少量完整內容驗證閱讀體驗與擴充方式。

## Solution

提供預先生成的生活場景圖文小讀本。學習者從場景列表進入獨立閱讀頁，依序閱讀場景圖、英文短文、常用短句與重點單字，並可展開繁體中文翻譯。

短文、常用短句與重點單字提供頁內播放，讓手機使用者留在讀本中取得英文語音。

第一版包含咖啡店買早餐、超市購物、街上問路三個場景。英文以初級到初中級、自然生活口語為主。每個場景包含一張圖、一篇 5–8 句的短文、4–6 個常用短句，以及 6–8 個重點單字。

## User Stories

1. As a 學習者, I want to 從場景列表選擇生活情境, so that 我能依當下需要開始閱讀。
2. As a 學習者, I want to 閱讀咖啡店買早餐的場景, so that 我能學習點餐與外帶相關用語。
3. As a 學習者, I want to 閱讀超市購物的場景, so that 我能學習找商品與結帳相關用語。
4. As a 學習者, I want to 閱讀街上問路的場景, so that 我能學習詢問位置與理解方向的用語。
5. As a 學習者, I want to 先看到生活場景圖, so that 我能先理解短文發生的情境。
6. As a 學習者, I want to 圖片與短文描述同一個情境, so that 我能利用視覺線索理解英文。
7. As a 學習者, I want to 閱讀 5–8 句的英文短文, so that 我能在幾分鐘內完成一次閱讀。
8. As a 初級到初中級學習者, I want to 讀到自然且難度適合的英文, so that 我能累積日常表達方式。
9. As a 學習者, I want to 自行展開或收合繁體中文翻譯, so that 我能先讀英文，再視需要確認意思。
10. As a 學習者, I want to 在短文中辨識重點單字與短句, so that 我知道哪些用語值得特別留意。
11. As a 學習者, I want to 在短文下方看到 4–6 個常用短句及中文意思, so that 我能整理可直接使用的表達。
12. As a 學習者, I want to 在短文下方看到 6–8 個重點單字、中文意思與簡短英文例句, so that 我能理解單字在語境中的用法。
13. As a 學習者, I want to 下方列出的學習重點對應短文中實際出現的內容, so that 閱讀與複習能連貫。
14. As a 學習者, I want to 切換到其他場景或回到場景列表, so that 我能接著閱讀下一個情境。
15. As a 學習者, I want to 直接開啟或重新整理某個場景的網址, so that 我能回到同一篇內容。
16. As a 手機使用者, I want to 圖片與文字配合螢幕寬度呈現, so that 我不必水平捲動才能閱讀。
17. As a 使用鍵盤或輔助技術的學習者, I want to 能操作翻譯與場景導覽並取得圖片的文字描述, so that 我能完成主要閱讀流程。
18. As a 內容維護者, I want to 透過新增一份場景資料與圖片加入內容, so that 我不必修改頁面或元件程式。
19. As a 內容維護者, I want to 新場景自動出現在列表並取得獨立閱讀網址, so that 我不必另外維護場景清單或逐頁建立路由。
20. As a 內容維護者, I want to 重用一致的閱讀版型, so that 每個場景都具有相同的學習結構。
21. As a 內容維護者, I want to 在內容檢查時看到明確錯誤位置, so that 我能修正缺少翻譯、缺圖片、識別碼重複或無效的用語關聯。
22. As a 網站維護者, I want to 透過單一內容讀取邊界提供場景資料, so that 未來更換內容來源時能保留閱讀元件。
23. As a 手機學習者, I want to 點選單字旁的按鈕直接聽英文發音並重播或停止, so that 我遇到不會念的字時能繼續閱讀，不必另開網站。

## Implementation Decisions

### 已確認的產品範圍

- 使用預先生成、經檢查後納入網站的圖片與內容；讀者開啟網頁時不觸發 AI 生成。
- 場景是完整的學習單位，包含場景圖、短文、短句與單字。短句指能在生活中使用的多字表達；單字指文中要學習的詞彙。
- 初版固定提供三個場景；數量不是架構限制。
- 主要頁面為場景列表與場景閱讀頁。每個場景有穩定識別碼及可直接開啟的網址。
- 閱讀順序固定為場景圖、英文短文、常用短句、重點單字；中文翻譯可展開。
- 實作使用 Astro 靜態頁面與原生 CSS；發布目標為 Cloudflare Workers Static Assets，自訂網域 `carlenglish.gravito.dev`。
- 2026-10-14 依使用者反映另開網站不方便，追加頁內發音。裝置語音因機械感遭拒絕，先前 Commons 真人錄音後改採 Kokoro `af_heart` 固定美式女聲合成的本地 MP3；不增加帳號、金鑰或執行時遠端語音整合。

### 最小可擴充結構

- **場景內容**：一個場景一份獨立的結構化資料，搭配本地圖片、全文/短句/單字音檔；第一版不使用資料庫。
- **內容讀取與驗證**：集中發現場景資料、檢查格式及關聯，提供場景摘要列表與依識別碼取得完整場景的能力。
- **共用閱讀元件**：場景圖、雙語短文、短句列表及單字列表接收一致的資料結構，不自行讀取檔案或依特定場景分支。
- **頁面組合**：列表與閱讀頁透過同一內容入口取得資料，採用共用路由規則，不為個別場景新增頁面實作。
- 新增內容可以需要重新建置網站；不要求執行中的網站即時發現新檔案。正常情況下只增加內容與圖片，不必更新人工登記清單。
- 第一版使用單一實際內容來源與簡單函式邊界，不建立通用外掛系統、來源註冊框架或尚未需要的多層抽象。

### 部署後的每日教材產製

2026-10-14 使用者確認：除了主動指定題材，也希望部署後交辦雲端電腦上的 dot，每天尋找不同生活題材或新聞，整理為教材並自動更新網站。dot 的排程、執行環境及發布串接留待部署後交辦；目前尚未啟用。

- 保留內容製作與網站呈現的分工：dot 選題、製作文字/圖片/固定聲線音檔，經檢查與建置後更新部署；讀者開頁時取得已完成的靜態內容。
- 每日增加可閱讀的新教材，保留既有教材與穩定網址。既有同格式短篇可沿用 JSON、共用版型、路由與內容驗證；每日產製不要求新增 CMS 或即時生成服務。
- 選題與難度依 `english-reading-coach` 及本人的閱讀理解紀錄決定。沒有新作答時可換題材、維持最近有依據的難度；日更天數與產品驗收不算閱讀能力進階證據。教練 skill 與參考資料目前在專案外，交辦 dot 時須一起提供。
- 新聞教材須讀取實際來源，記錄來源連結、媒體、發布/更新日期及取用日期，明確區分教練原創、教學簡化版與原版閱讀任務。原版完整新聞在來源網站閱讀，教材提供連結與閱讀支援。
- 目前支援的是 5–8 句短篇；較長文章的段落/篇幅契約、新聞來源與日期的頁面呈現尚未實作，須沿集中內容入口及共用 Reader 擴充並驗證後才宣稱支援。日更產製流程與長文能力分開驗收。
- 後續每日自動上站須以內容、圖片/語音品質及建置檢查通過為條件；失敗保留最後成功的網站版本，不能將未完成資產或未查證的新聞發布。網站已使用 Cloudflare Workers；每日發布流程與失敗回復方式仍待設計與驗收。

### 場景內容契約

| 內容 | 最小規格 |
| --- | --- |
| 場景識別碼 | 全站唯一且穩定，供網址與內容識別使用；標題修改不應自動改變網址 |
| 標題、分類、難度 | 可供列表與閱讀頁使用；分類與難度先作為內容描述，不代表初版必須提供篩選功能 |
| 場景圖 | 一張圖片資產及替代文字，與短文的主要人物活動和情境一致 |
| 短文 | 有順序的 5–8 個英文句子，各有對應的繁體中文翻譯 |
| 常用短句 | 4–6 筆，每筆具有場景內穩定識別碼、英文表達、繁體中文意思及音檔 |
| 重點單字 | 6–8 筆，每筆具有場景內穩定識別碼、英文詞彙、繁體中文意思、簡短英文例句及音檔 |
| 文中重點 | 明確關聯到本場景中的單字或短句；不依全域字串搜尋猜測對應關係 |

- 建議的標註方式：將英文句子表示為有順序的文字片段，片段保留原文，並可引用單字或短句的識別碼。同一片段可同時關聯短句及其中的單字，避免重疊標註造成重複文字或遺漏標點。
- 下方列出的每個單字與短句都至少在短文中有一處明確關聯；文中所有引用都必須存在於該場景。原文可保留自然的大小寫或詞形變化。
- 初版重點標示以閱讀辨識為目的，不要求點擊跳轉、彈出解釋或互動練習。
- 驗證必須涵蓋必要欄位、非空內容、識別碼唯一性、引用完整性、圖片存在、三類音檔的路徑/資產/固定聲線/英文與檔案 SHA-256，以及初版內容數量限制。錯誤須指出場景與問題欄位，不能把不完整內容靜默當成成功。
- 格式驗證不等於內容品質驗證；自然英文、中文意思、圖文一致性與難度需另做人工檢查。

### 閱讀行為與基本品質

- 建議預設收合短文的中文翻譯；展開與收合不改變英文內容。切換場景後顯示新場景的翻譯內容，不殘留前一篇。
- 支援桌面與手機直向閱讀，圖片保持比例，長內容正常換行。
- 使用語意化標題、連結與按鈕；翻譯控制可用鍵盤操作並表達展開狀態，場景圖提供有意義的替代文字。
- 無效場景網址顯示找不到場景的訊息並提供回到列表的入口，不展示任意其他場景。
- 外觀細節在第一個完整場景中確定；不另外增加一輪產品功能規劃。

### 頁內發音

- 三篇讀本的全文、15 個短句及 24 個重點單字各有本地 MP3；全部使用 `content/audio/voice-profile.json` 中同一 Kokoro `af_heart` 美式女聲。模型的 Apache-2.0 資訊不等於生成 MP3 自動適用該授權；介面不稱真人錄音。
- 場景 `audio`、`phrases[].audio`、`words[].audio` 均為必填，恰有 `src`、`voiceId`、`textSha256`、`sha256`。路徑限本地 `/audio/stories/`、`/audio/phrases/`、`/audio/words/`；驗證精確英文、相同聲線 ID 與檔案 SHA-256。全文英文由 `canonicalStoryText` 將每句片段原樣串接、句間加一個空格；英文改動須重製該音檔。
- 播放不呼叫裝置 TTS 或第三方服務，不提供裝置語音自動回退。
- 不自動播放。每頁只使用一個 Audio；點選另一單字、短句或全文會停止先前播放。同項重新點擊從頭播放；全文另有暫停、續播、從頭及停止控制。
- 分別顯示準備中、播放中與結束狀態；只有收到開始事件後才能宣稱已播放。停止、換字或離開頁面後，舊播放的回呼不得覆蓋當前狀態。
- 不支援播放、音檔載入/格式/播放失敗、8 秒未開始或播放中停滯 15 秒時，顯示可理解的提示並解除等待狀態；正常長篇依進度事件持續播放，不因總長超過 15 秒而中斷。暫停期間不計停滯時間。頁面隱藏或離開時停止播放。
- 按鈕至少 44px 高，支援觸控、鍵盤與可辨識的輔助名稱；狀態變更以禮貌的 live region 呈現。停用 JavaScript 時仍能閱讀完整內容。
- 音檔隨網站提供。使用者已接受 coffee、aisle、短句及 22.1 秒全文樣本的自然且一致聲線；全部 42 段的自然度與發音正確性仍須實聽確認；尚未建立離線快取。

## Testing Decisions

使用者已確認：以瀏覽器驗證完整閱讀流程，另驗證內容錯誤攔截與只靠資料新增場景的擴充能力。

- **主要測試邊界：使用者可見的網站。** 從列表選擇場景，確認圖片、短文、短句與單字正確顯示；操作翻譯及場景切換；直接開啟並重新整理場景網址。檢查可觀察的行為，不斷言內部元件樹、函式呼叫次數或 CSS 類名。
- **必要的內容驗證邊界：集中內容入口。** 使用有效資料及少量具代表性的無效資料，確認缺少翻譯、缺圖片、重複場景識別碼、懸空引用、未被文中引用的學習項目與數量不符會得到可定位的錯誤。這些是瀏覽器正常流程無法充分覆蓋的維護行為。
- **擴充驗收：** 測試環境僅加入第四個場景的合法內容與所需資產，經正常建置後確認自動出現在列表、能直接開啟獨立網址，且完整使用共用閱讀版型及音訊控制；無須修改頁面、元件、路由宣告或人工場景清單。相同英文的全文、短句與單字可重用既有音檔，測試資料不計入初版三個正式場景。
- **行動裝置與操作驗收：** 以代表性的手機寬度檢查沒有非預期水平捲動、文字沒有截斷、圖片比例正常；確認鍵盤能操作場景導覽與翻譯控制。
- **標註驗收：** 確認單字位於短句內、同一用語重複出現時，渲染後的句子仍保留正確順序、空格及標點，且關聯有效。
- **錯誤網址驗收：** 未知場景有明確提示與返回入口。
- **人工內容驗收：** 三個場景均符合句數與項目數量要求，英文自然且難度適合，翻譯正確，圖片與短文情境一致；格式驗證或模型自評不能代替這項檢查。
- **頁內音訊行為：** 在正式建置中，以可控制的 Audio 驗證三類固定音檔、跨類切換、短文暫停/續播/從頭/停止、舊事件與 Promise 隔離、啟動/停滯逾時、頁面生命週期及可見錯誤。桌面亮暗及手機 Chromium/WebKit 檢查按鈕、鍵盤與版面；以真實瀏覽器另檢查音檔可載入並完成播放。這些結果不代表聲音自然度已驗證。
- **實機發音驗收：** 在實際使用的手機瀏覽器聽到正確的單字、短句與全文，切換時不重疊，全文控制有效且不需離開讀本。全部 42 段的實際語音與觸控品質另行記錄，不能由手機寬度模擬取代。
- **測試先例：** 初次制定規格時專案沒有既有程式、測試或品質閘門。現已採內容入口測試、Playwright 與第四場景隔離擴充驗收，以 `pnpm run verify` 執行完整檢查；證據記錄在 `docs/implementation.md`。

## Out of Scope

- 登入、會員、收藏、個人學習紀錄與跨裝置同步。
- 測驗、評分、間隔複習、遊戲化或完整課程系統。
- 讀者輸入主題後即時生成文章或圖片，以及相關 AI API、金鑰或計費整合。
- 資料庫、CMS、內容管理後台或遠端內容 API 的實際整合。
- 逐句朗讀、獨立音檔下載介面、語音辨識與發音評分；頁內全文、短句與單字發音已納入範圍。
- 多語系平台、外掛架構、通用課程引擎與為假設需求建立的抽象。
- 每日教材自動產製與發布、長文格式及新聞來源呈現；現有三篇短文已另行發布。
