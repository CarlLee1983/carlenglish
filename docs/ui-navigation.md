# 分級與教材導覽

首頁 `/` 先選初級、中級或高級。目錄分別為 `/levels/beginner/`、`/levels/intermediate/`、`/levels/advanced/`。所有讀本繼續使用原有 `/scenes/<id>/` 網址，不新增遠端服務、資料庫或依賴套件。

## 內容分組

`src/lib/catalog.ts` 統一處理分級、目錄主題與推薦；JSON 的 `level` 仍是難度來源。

| 原始 `level` | 導覽級別 |
| --- | --- |
| 入門、初級、初級至初中級 | 初級 |
| 中級、中級至中高級 | 中級 |
| 中高級、進階、高級 | 高級 |

分組是讀本導覽規則，不是年齡、學校年級或 CEFR 能力認證。保留原始難度文字；未知標籤由 `validate:content` 及建置攔截，訊息包含場景 ID 與標籤，不能讓教材默默消失。新教材沿用已支援的標籤即可自動取得目錄入口。內容順序沿用檔名排序，主題來自該級別的 `category`，空級別仍有可直接開啟的頁面與初級入口。

## 目錄操作

- 卡片優先顯示中文生活情境，附英文標題、主題、原始難度與實際短文／短句／單字數量。桌機多欄，窄手機單欄，圖片保持原比例。
- 搜尋比對中文標題、英文標題與生活主題，忽略大小寫、前後空白；多個關鍵字都須符合。生活主題與搜尋可以一起使用。
- `q` 與 `category` 保存在網址。輸入搜尋文字更新目前歷史紀錄；選主題或清除篩選建立新紀錄，重新整理、上一頁與從讀本返回會還原條件。進入讀本的連結也攜帶這兩個參數，讀本返回與同級推薦沿用條件；不使用瀏覽器儲存。
- 不存在的主題參數回到全部主題；搜尋無結果時顯示提示與清除篩選按鈕，結果數以輔助技術可讀的狀態呈現。
- 停用 JavaScript 時隱藏搜尋與篩選控制，完整列出該級別教材，仍可用連結閱讀；網址參數不會限制靜態內容。

## 閱讀與驗證

閱讀頁保留圖文、翻譯、標註與本地音訊控制；上方提供短文、短句、單字的段落連結。返回連結指向所屬級別；推薦最多三篇同級教材，不列出自己。全站頁首可直接切換程度。

`pnpm run verify` 包含分級對照／未知標籤／順序／推薦上限測試、正式瀏覽器操作，以及隔離副本新增 42 篇混合級別教材的擴充驗收。測試涵蓋搜尋、主題、空狀態、重新整理與返回、鍵盤及無 JavaScript。桌機亮暗色、390px／320px 手機 Chromium、手機 WebKit 沿用既有檢查。

本次不新增或重製正式教材、圖片與音檔，未提交的其他工作仍在原 checkout。程式與分級導覽可以一併回復，沒有內容資料遷移；既有場景網址與本地資產維持有效。已依使用者於 2026-10-14 的部署授權發布，整合主分支的 43 篇教材，分組為初級 27 篇、中級 10 篇、高級 6 篇。此次直接部署的 UI／SEO 變更已整理於 `ui/level-entry-catalog` 分支的 PR；合併前，`main` 自動部署會使用主分支版本。實際手機的觸控與音訊仍需實機確認，模擬瀏覽器不代替使用者驗收。
