# 分級與教材導覽

首頁 `/` 先選初級、中級或高級。目錄分別為 `/levels/beginner/`、`/levels/intermediate/`、`/levels/advanced/`。所有讀本繼續使用原有 `/scenes/<id>/` 網址，不新增遠端服務、資料庫或依賴套件。

首頁以既有咖啡店場景插畫呈現看圖閱讀；若此場景不在教材清單，改用第一篇教材。插畫由 Astro 在建置時產生響應式 WebP，原始教材圖片維持不變。生活讀本與文章篇數皆使用次要文字層級，手機首屏仍完整顯示初級入口。

## 內容分組

`src/lib/catalog.ts` 統一處理分級、目錄主題與推薦；JSON 的 `level` 仍是難度來源。

| 原始 `level` | 導覽級別 |
| --- | --- |
| 入門、初級、初級至初中級 | 初級 |
| 中級、中級至中高級 | 中級 |
| 中高級、進階、高級 | 高級 |

分組是讀本導覽規則，不是年齡、學校年級或 CEFR 能力認證。保留原始難度文字；未知標籤由 `validate:content` 及建置攔截，訊息包含場景 ID 與標籤，不能讓教材默默消失。新教材沿用已支援的標籤即可自動取得目錄入口。內容順序沿用檔名排序，主題來自該級別的 `category`，空級別仍有可直接開啟的頁面與初級入口。

## 目錄操作

- 卡片優先顯示中文生活情境，附英文標題、主題、原始難度與實際短文／短句／單字數量。桌機多欄，窄手機單欄，圖片保持原比例。
- 搜尋比對中文標題、英文標題與生活主題，忽略大小寫、前後空白；多個關鍵字都須符合。生活主題與搜尋可以一起使用。
- 搜尋與主題欄位使用獨立的控制項邊框色，亮暗色對背景皆至少 3:1；一般分隔線繼續使用較淡的色彩。
- `q` 與 `category` 保存在網址。輸入搜尋文字更新目前歷史紀錄；選主題或清除篩選建立新紀錄，重新整理、上一頁與從讀本返回會還原條件。進入讀本的連結也攜帶這兩個參數，讀本返回與同級推薦沿用條件；不使用瀏覽器儲存。
- 不存在的主題參數回到全部主題；搜尋無結果時顯示提示與清除篩選按鈕，結果數以輔助技術可讀的狀態呈現。
- 停用 JavaScript 時隱藏搜尋與篩選控制，完整列出該級別教材，仍可用連結閱讀；網址參數不會限制靜態內容。

## 文章入口

首頁的「新聞與貼文」區塊位於分級入口之後，頁首可直接連到 `/#articles`。文章沿用新聞軌／貼文軌與 N／S 級別，從 `content/articles/` 取得資料，使用 `/articles/<id>/`；場景的初／中／高級目錄繼續只列生活讀本。文章保留其來源、雙語閱讀、關鍵詞與可展開的讀後提問答案，返回首頁的行為沿用原設計。

改寫文章在本文前顯示媒體與「閱讀原文」連結；原文標題、發布／事件／改寫／取用日期保存在預設收合的「查看日期與改寫資訊」中，可用鍵盤操作，也不需要 JavaScript。背景說明位於本文與翻譯之後。

## 閱讀與驗證

閱讀頁保留圖文、翻譯、標註與本地音訊控制；上方提供短文、短句、單字的段落連結。返回連結指向所屬級別；推薦最多三篇同級教材，不列出自己。全站頁首可直接切換程度。

場景圖片保持完整比例，桌機高度上限 360px、手機 260px；圖片、本文與朗讀操作的順序維持一致。音訊播放狀態留在操作旁，固定聲線與音源製作資訊移至短文翻譯之後，讓第一段英文更早出現。

`pnpm run verify` 包含分級對照／未知標籤／順序／推薦上限測試、正式瀏覽器操作，以及隔離副本新增 42 篇混合級別教材的擴充驗收。測試涵蓋搜尋、主題、空狀態、重新整理與返回、鍵盤及無 JavaScript。桌機亮暗色、390px／320px 手機 Chromium、手機 WebKit 沿用既有檢查。

本次不新增或重製正式教材、圖片與音檔，未提交的其他工作仍在原 checkout。程式與分級導覽可以一併回復，沒有內容資料遷移；既有場景網址與本地資產維持有效。已依使用者於 2026-10-14 的部署授權發布，整合主分支的 43 篇教材，分組為初級 27 篇、中級 10 篇、高級 6 篇。此次直接部署的 UI／SEO 變更已整理於 `ui/level-entry-catalog` 分支的 PR；合併前，`main` 自動部署會使用主分支版本。實際手機的觸控與音訊仍需實機確認，模擬瀏覽器不代替使用者驗收。

## 獨立分級單字庫

首頁先進初級單字庫，各級讀本目錄也有同名程度的 `/vocabulary/<level>/` 入口。單字庫另行編選，與來源讀本、閱讀完成度及詞頻排名無關；三組都有編選原則與詞表出處。可直接切換程度，或返回首頁。搜尋結果同時決定列印範圍與字卡範圍；網址的 `q` 保存搜尋，`view=cards` 開啟字卡。重新整理、返回其他搜尋或模式時會從目前結果第一張開始；同頁查看來源與返回字卡會保留目前卡片與翻面狀態。

字卡僅提供當次自由練習，不變更複習卡、FSRS 排程或教材。進入原生 dialog 的全視窗練習後，背景頁面保留原捲動位置，底部操作維持可見。字卡以原生橫向捲動與吸附換張，保留雙指縮放，長例句在卡片內直向捲動。換卡按鈕使用連續位移，快速連按改往最新目標；方向鍵及「減少動態效果」即時切換。字卡在進入時懶載入 Three.js WebGL 場景，紙卡的厚度、光照、陰影與後方疊卡由真正的幾何與材質呈現；網頁文字維持原生語意與捲動。入場有一次可中斷的 420ms 抽卡動作，觸控／滑鼠翻面為可反向中斷的 560ms 旋轉，約 190ms 轉到側面、略超過再落定；翻轉時紙卡下沉、後方疊卡退到遠側邊緣之後，像從牌堆拿起，讓側面停留數幀而不像直接換面，正反面維持相同尺寸，長文字各自捲動。單一時間軸將同一個角度套用到 WebGL 紙面與文字，原生橫向捲動則控制紙卡傾斜及深度。只有目前卡片與其語意上的一面供輔助功能讀取，翻面不改變主要操作位置。

資訊按鈕及來源連結開啟同一練習畫面的來源面板；返回、Escape 或瀏覽器返回先關來源，保留當前字卡與翻面狀態。退出練習回到原按鈕與清單位置。換字、滑動、查看資訊、退出、切到背景與列印均停止發音；過期的音訊回呼不覆蓋新字，載入失敗可原卡重試。列印暫時解除練習焦點，輸出目前搜尋結果與授權；關閉後恢復原練習，已退出則不重新開啟。

沒有結果時提供清除搜尋，練習與列印按鈕停用。無 JavaScript 仍有完整詞彙、來源與列印版。手機瀏覽器模擬與200%根字體測試不代表實機、系統字級或實際瀏覽器工具列驗收；桌面滑鼠使用按鈕／鍵盤，觸控板與觸控裝置使用原生橫滑。

若換卡動畫尚未完成就點發音，會先完成到最新目標字再播放。取消發音跟隨新輸入或換字，不把上一段動畫剩餘的捲動事件當成新手勢。

Three.js 畫布僅為視覺層，不接收觸控或輔助功能焦點；目前卡片、解答、發音與歷史紀錄仍由字卡控制器管理。像素比上限為 2，靜止時不持續繪製。來源面板、列印及頁面隱藏暫停同一場景，返回後保留當前單字與解答；離開練習、WebGL context 失效或啟用減少動態效果會釋放場景資源。非同步載入後會再次確認練習仍開啟，避免離開後掛載舊畫布。WebGL 或場景下載失敗時直接使用原生字卡。
