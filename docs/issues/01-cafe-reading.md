# 01: 完成咖啡店圖文閱讀流程

**What to build:** 學習者可以從場景列表進入「咖啡店買早餐」，依序看場景圖、讀英文短文、展開繁體中文翻譯，再閱讀常用短句與重點單字。從第一個場景就使用獨立內容資料、集中讀取與驗證、共用閱讀版型及自動產生的場景入口，讓後續增加場景只需加入內容與圖片。本票交付可在本地啟動、操作及驗證的完整網站，不只是架構或元件。

**Blocked by:** None (can start immediately).

**Status:** completed

- [x] 建立最少必要的可執行網站與檢查工具，記錄安裝、啟動、建置與測試命令；框架依實作環境選擇，不額外建立平台抽象。
- [x] 完成一張預先生成的咖啡店買早餐場景圖，提供有意義的替代文字；圖片與短文主要活動一致，讀者開啟網站不觸發 AI 生成。
- [x] 咖啡店包含 5–8 句初級到初中級英文短文及逐句繁體中文翻譯、4–6 個常用短句及中文意思、6–8 個重點單字及中文意思與簡短英文例句。
- [x] 從場景列表可進入咖啡店閱讀頁並返回列表；場景使用穩定識別碼與獨立網址，直接開啟或重新整理均能看到正確內容，修改標題不會自動更改網址。
- [x] 閱讀頁依序呈現場景圖、英文短文、常用短句、重點單字；短文翻譯預設收合，可展開及收合且不改變英文原文。
- [x] 每個場景採獨立結構化內容，具有識別碼、標題、分類、難度、圖片與學習內容；由單一入口自動發現並驗證，再提供給共用列表及閱讀版型。不使用人工場景登記清單、個別場景路由實作或依場景名稱分支的閱讀元件。
- [x] 文中重點明確引用本場景的單字或短句識別碼，且下方每個學習項目至少有一處文中引用；重疊或重複出現的用語仍保留正確文字順序、空格與標點，不依全域字串搜尋猜測關聯。
- [x] 集中內容驗證會攔下必要欄位缺失或空白、缺少翻譯、圖片不存在、場景或同類學習項目識別碼重複、懸空引用、未被引用的學習項目及數量不符；錯誤指出場景與問題欄位，不靜默接受不完整內容。
- [x] 無效場景網址顯示找不到場景的訊息及回到列表的入口，不回退成任意其他場景。
- [x] 手機與桌面都能完整閱讀；代表性手機寬度沒有非預期水平捲動或截斷，圖片保持比例。使用語意化標題、連結與按鈕，鍵盤可操作導覽與翻譯，翻譯控制表達展開狀態。
- [x] 瀏覽器測試涵蓋列表進入閱讀頁、內容顯示、翻譯展開收合、直接開啟與重新整理網址及錯誤網址；內容入口測試涵蓋上述無效內容與標註邊界。測試斷言可觀察行為，不綁定元件樹或樣式類名。
- [x] 完成咖啡店英文自然度、翻譯、難度與圖文一致性的人工內容驗收並記錄結果；執行所選技術棧的適用品質檢查與建置，記錄結果及未解問題，不能以格式驗證代替內容驗收。

範圍依「CarlEnglish：看圖學生活英文」規格。內容與呈現分離，但不預先加入資料庫、CMS、多來源框架、登入、測驗、學習紀錄、音訊或搜尋；本票不包含部署、提交或遠端發布。
