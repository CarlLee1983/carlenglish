# 02: 加入超市與問路，完成多場景學習與擴充驗收

**What to build:** 學習者可以在咖啡店買早餐、超市購物、街上問路三個完整場景之間切換，持續使用一致的圖文閱讀方式。內容維護者能依照操作說明，只新增場景內容與圖片就擴充網站，並取得自動出現的列表入口與獨立閱讀網址。

**Blocked by:** None — 01 已於 2026-10-14 完成人工驗收並結案。

**Status:** completed — human content acceptance confirmed

- [x] 使用第一張票的既有內容契約，各新增一份超市購物及街上問路內容與預先生成的場景圖；加入兩個場景本身不需修改頁面、閱讀元件、路由宣告或人工登記清單。
- [x] 每個新增場景包含 5–8 句英文短文及逐句繁體中文翻譯、4–6 個常用短句及中文意思、6–8 個重點單字及中文意思與簡短英文例句；具有分類、難度、穩定識別碼、圖片替代文字與有效文中關聯。
- [x] 三個正式場景自動出現在列表，均能從列表進入、直接開啟或重新整理獨立網址，使用相同閱讀版型，並可返回列表及切換到其他場景。
- [x] 跨場景切換後，圖片、短文、翻譯、短句與單字全部屬於當前場景；先展開上一個場景的翻譯再切換，也不殘留上一個場景的內容。
- [x] 以瀏覽器測試涵蓋三個場景的讀取、跨場景切換及翻譯操作，並驗證新增內容通過既有格式與關聯檢查；保留第一張票的閱讀與錯誤處理行為。
- [x] 在隔離的測試環境只加入第四個合法場景的資料與圖片，經正常建置後驗證它自動出現在列表、獨立網址可直接開啟與重新整理、完整圖文及學習項目正確呈現。此測試不得為第四場景修改頁面、元件、路由或人工清單；第四場景不納入正式三場景內容，也不污染正式建置。
- [x] 提供新增場景的操作說明，包含最小內容欄位、文中引用、圖片與替代文字、識別碼穩定性、驗證與重新建置步驟，以及如何根據錯誤訊息修正資料；說明內容新增不需改動網站呈現程式。
- [x] 在代表性手機寬度與桌面檢查三個場景，確認新增文字長度或圖片不造成截斷、非預期水平捲動或比例失真；鍵盤仍可完成導覽及翻譯操作。
- [x] 完成三個場景的人工內容驗收，確認英文自然且符合初級到初中級程度、中文正確、短句實用、學習重點對應原文且圖文一致；保留仍適用的咖啡店驗收結果，新增或變更內容補做檢查。
- [x] 執行受影響測試、適用完整品質檢查與正式建置，記錄第四場景擴充證據及檢查結果；完成規格對照，所有必要驗收條件通過後才能結案。

範圍依「CarlEnglish：看圖學生活英文」規格。分類及難度仍只是內容描述，不新增篩選介面；不加入即時生成、CMS、帳號或學習紀錄。本票不包含部署、提交或遠端發布。
