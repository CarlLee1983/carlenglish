# 生活讀本朗讀體驗改善

狀態：使用者於 2026-10-25 選擇 A「獨立專注跟讀」，正式整合、自動回歸與獨立審查已完成；體驗仍待使用者實際試用。證據見 [驗證紀錄](read-aloud-verification.md)，比較原型與決策記於 `.scratch/design-experience/follow-along/SESSION.md`。

## 目標與現況

改善生活讀本的聆聽、逐句跟讀與中斷後接續體驗，尤其照顧初級學習者。用語見 [GLOSSARY.md](../GLOSSARY.md)。

目前生活讀本已有固定 Kokoro `af_heart` 美式女聲的整篇、短句與單字音檔；播放器可在同頁暫停與繼續，但沒有語速選擇、逐句音檔或句子時間標記。切到背景或離頁會停止並歸零。新聞與經典尚未提供這個播放器；經典現有的篇章續讀與音訊接續是不同概念。

## 已確認的產品決策

2026-10-25，使用者對第一輪 Q1–Q4 回覆「全照建議」。

1. **教材範圍**：涵蓋所有生活讀本；新聞與經典留待另一輪工作。
2. **逐句導讀**：初級預設播放一句後停下跟讀，由學習者手動前往下一句；保留連續朗讀切換。目前句子須有標示，提供重聽、上一句與下一句。
3. **語速**：提供 `0.7×／0.8×／0.9×／1×`。未手動選擇時，初級預設 `0.8×`，其他級別預設 `1×`；手動選擇後，後續教材沿用該選擇，整篇、短句與單字皆適用。慢速清晰度仍須實聽確認。
4. **接續朗讀**：關頁或切到背景後保留每篇最後聽到的句子。回頁顯示「接續第 N 句」，使用者點擊後從該句開頭播放，不自動開始。進度限同一瀏覽器。

2026-10-25，使用者對第二輪 Q5–Q8 回覆「全照建議」。

5. **音檔與模式銜接**：沿用固定美式女聲製作逐句音檔，逐句與連續模式使用同一批音檔，以句末停下或接下一句區分。句間停頓的自然度仍須實聽確認。取捨見 [ADR 0003](adr/0003-sentence-audio-for-guided-reading.md)。
6. **試聽與停止**：正文播放中點單字或短句，先暫停正文再試聽；聽完保留原句，由使用者手動繼續。停止也保留位置；「從頭播放」從第一句開始。
7. **聽完一篇**：顯示「本篇已聽完」與「再聽一次」；再次開啟仍顯示已聽完。「再聽一次」從第一句開始。不自動播放其他教材，聽完不代表已學會。
8. **模式偏好**：未手動選擇時，初級預設逐句跟讀，中／高級預設連續朗讀；手動切換後，後續教材沿用該選擇。

2026-10-25，使用者對第三輪 Q9–Q11 回覆「全照建議」。

9. **閱讀版面與翻譯**：保留整篇正文，在原位置標示目前句子並提供逐句播放入口；中文翻譯維持預設收合。
10. **失敗回復**：某句播放失敗就停在該句，提示重試，不跳過。無法儲存進度時仍可播放，提示本次無法保存；教材更新使舊位置失效時，提示從頭開始。
11. **驗收方式**：實作後完成全套檢查，驗證切速、換句、試聽插播、離頁接續與手機版面；交由使用者以實際手機抽聽初級代表篇，確認慢速清晰度、句間停頓與跟讀節奏。自動測試與使用者實聽分別記錄。

### 2026-10-25 跟讀流程重新設計

使用者指出：「這樣的設計頁面要跟著滑動，ui ux 體驗不佳跟讀功能應該額外設計」。因此重新打開 Q9 對跟讀介面的結構選擇：一般閱讀保留全文；跟讀須另外設計，使目前句子、重聽與下一句保持在同一視野，避免往返捲動。比較後使用者選擇 A「獨立專注跟讀」。一般閱讀只有跟讀入口；跟讀採原生全螢幕 dialog，固定目前句子、翻譯開關、語速與主操作，避免正文與控制分離。播放／暫停／繼續／下一句／完成由同一顆主按鈕處理；重聽與上一句維持次要操作，跳句、模式與從頭朗讀收進設定。退出或 Escape 停止並返回當前正文句子，背景或離頁保存位置並關閉跟讀；進入不自動發聲。既有聲線、音檔、語速與進度格式仍有效，前一版自動測試不代表新體驗已被接受。

## 可觀察驗收情境

以下是待實作後驗證的條件，不是已通過的結果。

- **首次使用與偏好**：沒有手動偏好時，初級以逐句跟讀與 `0.8×` 開始，中／高級以連續朗讀與 `1×` 開始；手動切換模式或四種語速後，後續教材沿用選擇。進頁不自動發聲，短句與單字沿用所選語速。
- **逐句跟讀**：在獨立專注畫面播放目前句子，句子、翻譯開關、語速與主操作同屏；句末停下，使用者可重聽或手動前往前後句。第一句與最後一句的導覽不會越界。
- **連續朗讀與切換**：句子依正文順序接續播放，標示與實際聲音對應；模式與語速切換不導致聲音重疊、跳過內容或丟失目前句子。
- **試聽插播**：退出專注跟讀後可到正文的單字或短句區試聽；退出會停止朗讀，試聽結束不自動返回正文，原句仍可手動重新進入並從句首播放。快速切換與舊媒體事件不會使已停止的播放復活。
- **停止與接續**：停止、切到背景或離頁後，仍保存該篇句子位置；回頁須手動點擊「接續第 N 句」，從句首播放。不同教材分別保存位置；從頭播放回到第一句。
- **聽完**：最後一句自然結束後顯示「本篇已聽完」，重新開頁仍可看到該狀態；再聽一次從第一句開始，不跳到另一篇，也不產生已掌握教材的宣稱。
- **失敗回復**：載入或播放失敗、瀏覽器拒絕播放時保留該句並提供重試，不自動跳過；無法儲存時播放仍可使用，提示無法保存。過期或不可用的接續位置不能使頁面出錯或跳到錯誤句子，應提示從頭開始。
- **內容與資產**：所有生活讀本的句子音檔與正文一致，沿用固定聲線；內容驗證可發現缺檔或錄音過期。新增合法教材仍沿用資料驅動的頁面生成方式。
- **閱讀與裝置**：正文、翻譯、短句、單字、複習與導覽仍可使用；保留無 JavaScript 時的閱讀能力。檢查桌機亮暗色、鍵盤操作、320px／390px 手機版面與 Chromium／WebKit 播放流程。
- **實聽**：使用者以實際手機抽聽初級代表篇，確認 `0.7×` 至 `1×` 的清晰度、同一聲線的一致性、連續模式停頓與逐句跟讀節奏。自動測試不能代替這項驗收。

## 建議實作順序

1. 確認既有本地語音生成工具可用，建立逐句音檔的資料、生成與驗證流程，先驗證代表篇再擴至全部生活讀本。
2. 延伸既有播放器的播放狀態，整合逐句／連續模式、語速、跳句與試聽插播，保留既有延遲事件與失敗處理的回歸保障。
3. 加入每篇句子位置與聽完狀態、語速與模式偏好的瀏覽器儲存，以及版本失效與儲存不可用的回復路徑。
4. 在既有正文版面整合控制、逐句入口、目前句子標示與狀態提示，檢查鍵盤及手機操作。
5. 更新內容維護與操作說明，執行 `pnpm run verify`、獨立審閱及實際瀏覽器操作，交付手機實聽入口與驗證紀錄。
