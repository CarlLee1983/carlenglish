## 驗收界線與回復

本批為原創教學創作，不取用第三方節目、角色或歌曲素材。使用者與孩子尚未實聽、試讀本批。此環境可核對文字、媒體與原生播放事件，無法主觀聆聽發音，也不能代替實機觸控或孩子難度驗收；個人閱讀證據維持原樣。

可依[共讀說明](elementary-play-make-study-guide.md)每次挑一篇，在自己的手機以 0.8× 播放句子、語塊與單字，確認沒有漏字、發音可懂且節奏適合，再用中文回答理解題。預期能從英文找到答案；可以重聽及使用翻譯，不以篇數或聽完當成已掌握的證據。

本次交付為本地教材更新，未提交、推送、建立 PR 或部署。若需回復本批，移除三個新 ID 的 JSON、WebP、48 段 MP3 及本批配套文件，只還原共用 README、內容指南與音源說明中的本批條目及總量。前批教材及共用素材都保留，沒有學習紀錄或資料遷移要回復。
