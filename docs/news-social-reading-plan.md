# CarlEnglish 新聞與社群貼文閱讀企劃

日期：2026-10-14。狀態：企劃，已經過 `/grill-with-docs` 確認。2026-10-14 使用者決定略過「先在對話取得閱讀證據」，直接實作網站的文章內容類型；原本延後的網站契約當天定案，見「網站文章契約」與 [ADR 0001](adr/0001-articles-separate-from-scenes.md)。

本企劃的目標，是把生活情境短篇一路銜接到能獨立讀懂 CNN 等媒體的一般新聞，以及 X 上的英文貼文。網站與閱讀證據並行推進：網站增加「文章」內容類型承載教材，各級別的篇幅與難度仍依實際作答調整；不以網站功能的完成代替閱讀能力的證據。

本企劃的讀者是網站擁有者本人，選題與級別依本人的閱讀證據安排，不另訂通用的能力分級；網站是公開的，所以真實材料的版權仍照公開標準處理。[場景與學習卡擴充企劃](expansion-plan.md) 處理兒童、中學生的生活情境，兩者的受眾與內容契約分開，只共用網站骨架與音訊規則。用語定義見 [CONTEXT.md](../CONTEXT.md)。

## 完成的定義

「讀懂」以理解行為判斷，而不是看讀完幾篇。讀完一則 CNN 一般新聞後，能用中文說出誰、做了什麼、何時、何地、為什麼重要，以及消息來自誰；能分辨記者陳述的事實、引述的說法與尚未證實的指控；生字只查會影響主旨的那幾個，不需要逐句翻譯。

讀完一則 X 貼文或一段 thread 後，能說出發文者想表達什麼、語氣是認真、反諷還是玩笑，以及它在回應什麼事件或貼文；看得懂常見縮寫與網路用語，並知道哪些內容還需要查證。

作答可以用中文，不把英文寫作能力列入判斷。真實新聞不限 CNN，也採用 AP、Reuters、BBC、NPR 等主流英文媒體；AP 與 Reuters 的句子較精簡，適合 N2–N3 銜接。政治、國際、商業、科技、天氣與災害屬於「一般新聞」。財經深度分析、法律判決全文、專欄評論與長篇調查報導屬於下一階段，不列入本企劃的完成條件。

## 現況與落差

現有讀本是 5–8 句、初級到初中級的生活對話；真實新聞通常 600–1,200 字，充滿專有名詞、引述與長名詞片語；X 貼文雖短，卻高度依賴上下文，還會省略主詞並大量使用縮寫。三者的主要落差如下。

| 面向 | 現有生活短篇 | CNN 一般新聞 | X 貼文 |
| --- | --- | --- | --- |
| 篇幅 | 5–8 句 | 15–40 段，600–1,200 字 | 1–5 句；thread 可達數十則 |
| 結構 | 時間順序的小故事 | 倒金字塔：標題、導言、細節、背景、引述 | 單句主張、回應、引用他人貼文 |
| 句型 | 短句、現在式與過去式 | 被動語態、同位語、長名詞片語、間接引述的時態後移 | 省略主詞與冠詞、片段句、反問 |
| 用語 | 生活物品與動作 | 機構縮寫、頭銜、數字與百分比、法律與政治詞彙 | 縮寫、俚語、表情符號、迷因 |
| 背景知識 | 不需要 | 需要人物、機構與事件前情 | 需要知道在回應什麼，以及發文者是誰 |
| 判讀 | 不涉及 | 區分事實、歸屬與指控 | 區分新聞、意見、反諷與未查證消息 |

## 閱讀階梯

新聞與貼文分成兩條軌道，都從教練原創內容開始，逐步過渡到真實材料。每一級以閱讀證據決定是否往上走；可以跳級試讀，讀不懂就退回上一級，不承諾固定週數。

### 新聞軌

| 級 | 名稱 | 內容 | 來源 | 進到下一級的證據 |
| --- | --- | --- | --- | --- |
| N0 | 生活短篇 | 現有場景讀本 | 原創 | 能說出故事主線，不需逐句翻譯 |
| N1 | 仿新聞短訊 | 6–10 句的社區或校園消息，有標題與導言 | 原創 | 能從標題猜出事件，並說出導言的人事時地 |
| N2 | 新聞簡報 | 真實事件改寫，3 段、120–200 字，保留標題句型與引述 | 教練依真實報導改寫，附來源 | 能分辨事實與引述，說出消息來源 |
| N3 | 標準新聞段落 | 真實事件改寫，300–500 字，保留原文的結構與歸屬句型 | 教練改寫，附來源 | 能說出全篇主旨與兩個以上的細節，指出不確定的說法 |
| N4 | 原文導讀 | 讀者到 CNN 讀原文，教材提供標題解析、背景卡、關鍵詞與段落提問 | 原文在來源網站，教材只放導讀 | 只靠導讀卡讀完原文，能回答段落提問 |
| N5 | 獨立閱讀 | 只給原文連結，讀後回答問題 | 原文 | 連續數篇不同題材都能達到「完成的定義」 |

### 貼文軌

| 級 | 名稱 | 內容 | 來源 | 進到下一級的證據 |
| --- | --- | --- | --- | --- |
| S1 | 仿貼文 | 教練寫的單則貼文與回覆，涵蓋常見縮寫與語氣 | 原創 | 能說出語氣與意思，不被縮寫卡住 |
| S2 | 機構與新聞帳號 | 新聞媒體、政府機構、企業的公開貼文，如 BREAKING、JUST IN 快訊 | 真實貼文的連結或嵌入 | 能說出快訊重點，知道要去哪裡查證 |
| S3 | thread 與引用貼文 | 多則串文、引用貼文與回覆鏈 | 真實貼文的連結或嵌入 | 能重建討論脈絡，分辨誰在回應誰 |
| S4 | 自由閱讀 | 自選帳號或話題，事後帶著卡住的貼文來問 | 真實貼文 | 大多數貼文不需協助就能判斷意思與語氣 |

貼文軌從階段 1 起就和新聞軌並行，不必等新聞軌讀到某一級。S2 起最好搭配同一事件的 N2 或 N3 新聞，讓背景知識在兩條軌道之間共用。

## 要教的閱讀技能

每篇教材從下列清單挑一到兩個重點，不一次全部講。技能清單也是之後安排難度與檢查覆蓋的依據。

新聞類的重點是標題語法，例如用現在式表示過去、用 to 表示未來，以及省略冠詞與 be 動詞，並熟悉 slams、eyes、mulls、probe 這類標題專用詞；接著是導言的人事時地、倒金字塔的閱讀順序、歸屬用語（said、according to、told CNN、officials say、sources familiar with）、模稜與指控用語（alleged、reportedly、could、is expected to）、間接引述的時態後移、被動語態與長名詞片語、同位語介紹人物，以及數字、百分比、日期與常見機構縮寫（Fed、GOP、NATO、UN）。

貼文類的重點是常見縮寫（tbh、imo、ngl、fwiw、iirc、ICYMI）、省略主詞的片段句、反諷與誇飾、thread 編號與 🧵、引用貼文與回覆的關係、hashtag 與迷因的引用，以及快訊格式（BREAKING、JUST IN、developing）與社群備註，搭配查證習慣：看帳號、看日期、找原始來源。

## 內容來源與版權

網站是公開的，所以真實材料一律採保守做法：不轉載新聞全文或大段原文。N2、N3 是教練依真實報導寫出的教學改寫，頁面標示「教學簡化版」，附上媒體名稱、原文連結、發布或更新日期與取用日期，沿用[現行規格](spec.md)中每日教材對新聞來源的要求。改寫用自己的話重寫，只沿用原報導的事實與段落邏輯，不照搬原文連續的句子；可保留一到兩句加引號並註明說話者的簡短引述；標題另擬，但刻意使用標題語法。N4、N5 只放導讀與連結，原文在來源網站閱讀；必要時引用標題或單句，並標出出處。

真實貼文使用官方嵌入或連結，必要時只摘錄一句。優先選用公眾人物、媒體與機構帳號，避免把一般個人帳號的貼文做成公開教材。原貼文刪除時，教材改為說明性內容或下架，不另存副本。

新聞圖片同樣有版權，文章類教材不使用原報導的照片；需要圖像時另做原創示意圖，或不放圖。

## 時效與背景知識

新聞會過時，但教材是閱讀練習，不是新聞服務。每篇真實新聞教材標示事件日期與改寫日期，並附一張背景卡，用中文交代人物、機構與前情。上站後一律保留：事件有重大後續時加一行註記與新報導連結，不改寫原本的內容，也不因過時下架；只有原報導撤回或更正錯誤時，才跟著修正或下架。原創的 N1 與 S1 不綁定時事，可以長期保留。

## 網站文章契約

文章是獨立於場景的內容類型，理由見 [ADR 0001](adr/0001-articles-separate-from-scenes.md)。每篇一份 `content/articles/<id>.json`，網址為 `/articles/<id>/`，首頁在場景之後依軌道列出全部文章；新增文章只需加入資料檔，不必改頁面或路由。

| 欄位 | 規格 |
| --- | --- |
| `id`、`title`、`titleEn` | 全站唯一且穩定的識別碼；中文與英文標題。英文標題刻意使用標題語法 |
| `track`、`stage` | 軌道為 `news` 或 `posts`；級別 N1–N5 屬於新聞軌、S1–S4 屬於貼文軌，必須相符 |
| `origin` | `original`（教練原創，人物、地點與帳號皆為虛構）或 `rewrite`（教學簡化版） |
| `source` | `rewrite` 必填，`original` 不得有：媒體、原文標題、HTTPS 連結、發布日期、取用日期；另有事件日期與改寫日期。日期為 `YYYY-MM-DD` |
| `paragraphs` | 新聞軌必填、貼文軌不得有：1–12 段，各有英文與繁體中文翻譯 |
| `posts` | 貼文軌必填、新聞軌不得有：1–12 則，各有發文帳號、英文、翻譯，可選擇回覆或引用前面出現過的帳號 |
| `background` | 選填的中文背景說明，交代人物、機構與前情 |
| `glossary` | 選填的 0–8 個關鍵詞，各有英文與中文；英文必須出現在本文中 |
| `questions` | 2–4 題中文讀後提問，各附參考答案；答案預設收合，不評分、不保存作答 |

級別是教學設計，不是量測結果。內容驗證會印出每篇文章的英文字數與平均句長，超出下表範圍時只顯示警告、不擋建置；貼文軌、N4、N5 不設範圍。2026-10-14 用 CEFR-J 詞表量測，一般新聞原文與入門短訊的進階詞比例幾乎相同（約 9%），難度主要來自句法與背景，所以不以詞彙比例分級。

| 級別 | 英文字數 | 平均句長 |
| --- | --- | --- |
| N1 | 80–150 | ≤ 15 字 |
| N2 | 120–250 | ≤ 18 字 |
| N3 | 300–500 | ≤ 22 字 |

第一版不附音檔，全文音訊待產音環境就緒後另行加入。真實貼文只放連結與一句摘錄，不載入 X 的嵌入腳本；第一版的 S1 是原創貼文，以網站自己的卡片樣式呈現。場景的 `level` 自由文字與擴充企劃的 `audience` 不受影響。

## 分階段交付

依「先取得閱讀證據，再做網站功能」排序。每一階段完成時，記錄實際作答與卡點，再決定下一階段的範圍。

| 階段 | 交付內容 | 完成條件 |
| --- | --- | --- |
| 0 企劃 | 本文件 | 已完成：grill 確認階梯、版權做法與延後決定 |
| 1 程度評估 | 在對話中試讀一篇 N1、一篇 N2、一則 S1，不改網站 | 2026-10-14 已提供教材；使用者選擇輔助閱讀、不作答，記為未評量 |
| 2 對話教練 | 由 `english-reading-coach` 在對話中帶讀 N1–N3、S1–S2 教材，預設直接解說閱讀重點，不出題評量 | 依使用者自述的閱讀負荷調整篇幅與難度；使用者想確認程度時，再改用作答取得閱讀證據；與階段 3 並行 |
| 3 文章內容類型 | 依「網站文章契約」支援段落、貼文、來源、背景、關鍵詞與讀後提問，首批上站 N1、N2、S1 三篇；全文音訊另外排入 | 規格中的內容驗證、瀏覽器測試與 `pnpm run verify` 通過，並在手機實際閱讀 |
| 4 上站內容 | 把階段 2 驗證過的 N1–N3 與 S1 轉成網站教材 | 每篇的來源、日期、改寫標示與人工內容檢查通過 |
| 5 導讀與貼文 | N4 原文導讀、S2–S3 貼文導讀 | 嵌入與連結正常，原文刪除或改版時的處理經過驗證 |
| 6 每日產製 | 交辦 dot 每日選題、製作並發布 | 沿用規格中每日教材的品質閘門與失敗回復，另行驗收 |

## 範圍外

本企劃不包含帳號、跨裝置同步、間隔複習與評分；不包含即時抓取新聞或貼文的服務，也不在讀者開頁時呼叫 AI 生成。財經深度分析、法律文件、專欄與長篇調查報導留到 N5 之後另行規劃。
