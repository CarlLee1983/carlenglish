## 驗收界線與回復

本批是原創教學內容，不使用第三方節目或歌曲素材。沒有更動個人閱讀證據，使用者與孩子尚未實聽、試讀本批。此環境可核對文字、媒體與原生播放事件，不能主觀聆聽發音，也不能代替實機觸控或孩子難度驗收。

試讀可依[共讀說明](elementary-help-observe-study-guide.md)每次挑一篇，在自己的手機以 0.8× 播放句子、語塊與單字，確認沒有漏字、發音可懂且節奏適合，再用中文回答理解題。預期能從英文找到答案；需要翻譯或重聽時仍可使用，不將篇數或聽完當成掌握證據。

本次授權為本地教材更新，未提交、推送、建立 PR 或部署。若需回復，移除三篇新 JSON、三張 WebP、三個 ID 對應的 48 段 MP3 與本批配套文件，還原 README、內容指南及音源說明中的本批條目；本批沒有共用或替換舊素材，既有場景與學習紀錄不受影響。
